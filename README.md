# 📧 Unbreakable Mailing System (Dr Monk)

A robust, full-featured desktop application built for high-performance email marketing, bulk SMTP management, and SMS routing. Designed to handle large-scale campaigns with real-time analytics and an intuitive, dark-mode UI.

## 🚀 Key Features

*   **Live Dashboard:** Real-time analytics tracking Total Emails, Live sends, Valid addresses, Campaign status, and Daily metrics.
*   **Advanced SMTP Room:** Auto-detects email providers, tests configurations, and supports Auto-Security (TLS, SSL, Plain) for reliable connections.
*   **Dynamic Email Generator:** Built-in faker integration to generate realistic names and emails, with options to include numbers, formatting, and direct database saving.
*   **Global SMS Gateways:** Pre-configured routing for major US carriers (AT&T, Verizon, T-Mobile, etc.) via SMS/MMS gateways for seamless bulk texting.
*   **Campaign Management:** Run multiple campaigns simultaneously. Features HTML template injection, dynamic variable replacement (e.g., `[Name]`), live preview, and scheduling.
*   **System History & Logging:** Comprehensive audit logs tracking total events, message statuses, and errors, with bulk export/clear functionalities.
*   **Proxy Management:** Built-in proxy rotation to maintain IP health during mass sending.

## 🛠️ Tech Stack
*   **Core Language:** Python
*   **Framework/UI:** CustomTkinter
*   **Database:** SQLite
*   **Integrations:** SMTP, psutil, faker, dnspython, pysocks.
